## 📖 পরিচিতি

**রূপসা জনকল্যাণ ফাউন্ডেশন** সিরাজগঞ্জ সদরের রূপসা এলাকার একটি অলাভজনক, স্বেচ্ছাসেবী সংগঠন। অসহায়, দরিদ্র ও গৃহহীন মানুষের পাশে দাঁড়িয়ে একটি সুন্দর, সুশৃঙ্খল ও মানবিক বাংলাদেশ গড়ে তোলাই এর লক্ষ্য।

এই রিপোজিটরি ফাউন্ডেশনের অফিসিয়াল ওয়েব প্ল্যাটফর্ম। এটি শুধু একটি তথ্যের ওয়েবসাইট নয়। সদস্য নিবন্ধন, ডিজিটাল আইডি কার্ড, QR যাচাই, দান গ্রহণ, সদস্য ড্যাশবোর্ড এবং পূর্ণাঙ্গ অ্যাডমিন প্যানেল নিয়ে একটি সম্পূর্ণ সদস্য ব্যবস্থাপনা সিস্টেম।

## 🚀 দ্রুত শুরু

### ১. ক্লোন করুন

```bash
git clone <your-repository-url>
cd WAmyNonProfitORG-org
```

### ২. লোকালি চালান

কোনো ইনস্টল বা বিল্ডের দরকার নেই। যেকোনো স্ট্যাটিক সার্ভার হলেই চলে।

```bash
npx serve .
# অথবা
python3 -m http.server 3000
```

> সাইটটি `<base href="/">` ব্যবহার করে, তাই এটি সার্ভারের রুট থেকে চালাতে হবে, সাব-ফোল্ডার থেকে নয়।

### ৩. Firebase কনফিগার করুন

1. Firebase Console-এ **Authentication → Sign-in method → Email/Password** চালু করুন।
2. **Firestore Database → Rules** ট্যাবে `firestore.rules`-এর পুরো কন্টেন্ট পেস্ট করে **Publish** করুন।
3. `firestore.rules`-এর `adminEmails()` এবং `.tz/.js/admin/js/admin-config.js`-এর `ADMIN_EMAILS`-এ একই অ্যাডমিন ইমেইল দিন।
4. Authentication-এ অ্যাডমিনের ইমেইল ও পাসওয়ার্ড দিয়ে একটি ইউজার তৈরি করুন।

### ৪. ডিপ্লয়

```bash
vercel --prod
```

অথবা GitHub-এ পুশ করলে Vercel নিজে থেকেই ডিপ্লয় করবে।

> নতুন কোড ডিপ্লয়ের পর ফিরতি ভিজিটররা যেন আপডেট পান, সেজন্য `sw.js`-এর `CACHE_VERSION` বাড়িয়ে দিন।

## 🔐 নিরাপত্তা

নিরাপত্তা এই প্রজেক্টের মূল ভিত্তি। সদস্যদের ব্যক্তিগত তথ্য সুরক্ষার জন্য নিচের ব্যবস্থাগুলো নেওয়া হয়েছে:

- **Deny-by-default Firestore Rules।** যা খোলা রাখা দরকার শুধু সেটুকুই স্পষ্ট করে খোলা
- **পাসওয়ার্ড কখনো Firestore-এ থাকে না।** সব অথেন্টিকেশন Firebase Authentication সামলায়
- **সদস্যের ব্যক্তিগত তথ্য (`members`)** শুধু অ্যাডমিন ও সংশ্লিষ্ট সদস্য নিজে পড়তে পারেন
- **`public_members` কালেকশন।** যাচাই পেজের জন্য শুধু অনুমোদিত সদস্যের সীমিত পাবলিক তথ্য, মোবাইল নম্বর মাস্ক করা
- **ডুপ্লিকেট ইমেইলে আবেদন** সার্ভার-সাইডে (rules-এ) আটকানো হয়
- **সেশন সুরক্ষা।** নিষ্ক্রিয়তায় স্বয়ংক্রিয় লগআউট, ভুল চেষ্টার লিমিট এবং রিসেট ইমেইলের কুলডাউন
- **ইনপুট স্যানিটাইজেশন ও HTML escape।** যাচাই পেজে সব মান escape করে দেখানো হয়
